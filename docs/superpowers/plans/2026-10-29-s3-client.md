# S3 Client Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Track work with the checkboxes below.

**Goal:** Deliver a runnable Electron S3 browser with a Finder-style tree and immediate-child file list backed by boto3.

**Architecture:** Electron main owns connections, encrypted credentials, and a newline-delimited JSON Python bridge. A context-isolated preload exposes a typed API. React owns presentation, per-node loading state, and navigation.

**Tech Stack:** Electron, electron-vite, React, TypeScript, Python 3.10+, boto3, Vitest, Playwright, electron-builder.

## Global Constraints

- Require Node.js 22 or newer and Python 3.10 or newer with boto3 installed.
- Keep filesystem access and credentials outside the renderer.
- Call `list_objects_v2` with `Bucket`, `Prefix`, and `Delimiter='/'`. Consume all paginator pages.
- Restrict browsing to the configured bucket and prefix.
- Every root and folder has an expand/collapse arrow and a refresh button.
- Selecting a folder shows its immediate folders and files in the right pane.
- Otherwise keep credentials in memory and clearly explain that the user must re-enter them after restarting.
- File transfer and modification are outside this browsing-focused scope.

## Task 1: boto3 worker

Files: `backend/s3_worker.py`, `backend/test_s3_worker.py`, `backend/requirements.txt`, `backend/requirements-dev.txt`.

Protocol: one request per line `{id, method: 'ping'|'list', params}`; respond `{id, result}` or `{id, error: {code, message}}`. `list` params are `{connection: {endpoint, accessKey, secretKey, sessionToken?, region, bucket, prefix}, prefix}`. Results are `{entries: [{key, name, kind: 'folder'|'file', size: number|null, modified: string|null, storageClass?: string}]}`. `ping` returns `{ready:true}`.

## Task 2: Electron shell and connections

Files: `package.json`, `electron.vite.config.ts`, `tsconfig.json`, `src/shared/types.ts`, `src/main/{index,connections,python-bridge}.ts`, `src/preload/index.ts`, `tests/connections.test.ts`.

Preload API:

```ts
interface S3API {
  connections(): Promise<{connections: Connection[]; secureStorage: boolean}>;
  saveConnection(input: ConnectionInput): Promise<Connection>;
  removeConnection(id: string): Promise<void>;
  list(connectionId: string, prefix: string): Promise<{entries: Entry[]}>;
  copyText(text: string): Promise<void>;
}
```

Public Connection: `{id,name,endpoint,bucket,prefix,region,hasCredentials}`. Input additionally accepts `accessKey`, `secretKey`, optional `sessionToken`, and optional `id`. A connection URI prefix `s3://bucket/path` resolves to bucket `bucket` and prefix `path/`.
